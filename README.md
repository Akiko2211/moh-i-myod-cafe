# Мох и Мёд 🌿🍯

Сайт уютной кофейни с онлайн-меню, корзиной, оформлением заказа и бронированием столиков на интерактивной схеме зала.

## Возможности

- **Меню** — 24 позиции в шести разделах (кофе, авторские напитки, чай и какао, завтраки, выпечка, десерты) с фильтрами по разделам. Данные загружаются с сервера из базы.
- **Корзина** — добавление товаров, изменение количества, подсчёт суммы. Содержимое сохраняется в браузере и не пропадает при перезагрузке страницы.
- **Оформление заказа без регистрации** — по имени и номеру телефона, с комментарием. Номер приводится к единому формату `+7XXXXXXXXXX`.
- **Чек на почту** — если покупатель указал email, после заказа ему приходит письмо со списком позиций и суммой.
- **Бронирование столика** — выбор даты, времени и количества гостей, затем свободного столика на схеме зала. Занятые столики и столики, где не хватает мест, недоступны для выбора. Сервер не допускает пересечения броней одного столика.
- **Подтверждение брони на почту** гостю.
- **Уведомления для кафе** — о каждом новом заказе и брони на почту администратора.
- **Адаптивная вёрстка** — корректное отображение на телефонах, планшетах, ноутбуках и больших мониторах, а также при изменении масштаба страницы. Закреплённая шапка и мобильное меню.

## Запуск

Нужен только **[Node.js](https://nodejs.org) версии 22.5 или новее**.

```bash
git clone https://github.com/Akiko2211/moh-i-myod-cafe.git
cd moh-i-myod-cafe
npm start
```

Сайт откроется по адресу http://localhost:3000

При первом запуске всё подготовится автоматически: установятся пакеты, создастся файл настроек `.env` и заполнится база данных. Без настройки почты сайт работает полностью, только письма не отправляются.

Для разработки — с автоматическим перезапуском сервера при изменении кода:

```bash
npm run dev
```

## Настройка почты

Чтобы письма отправлялись, заполните файл `.env` (он создаётся при первом запуске). Пример для Яндекс Почты:

| Переменная | Значение |
|------------|----------|
| `MAIL_HOST` | `smtp.yandex.ru` |
| `MAIL_PORT` | `465` |
| `MAIL_USER` | адрес ящика, с которого уходят письма |
| `MAIL_PASS` | пароль приложения (создаётся в настройках Яндекс ID → «Пароли приложений») |
| `ADMIN_EMAIL` | куда приходят уведомления о заказах и бронях; если не указан — на `MAIL_USER` |

В настройках Яндекс Почты нужно разрешить доступ почтовым программам: «Все настройки» → «Почтовые программы».

## API

| Метод | Адрес | Описание |
|-------|-------|----------|
| `GET` | `/api/products` | список позиций меню |
| `POST` | `/api/orders` | оформить заказ |
| `GET` | `/api/tables` | столики и их положение на схеме |
| `GET` | `/api/tables/busy?date=ГГГГ-ММ-ДД&time=ЧЧ:ММ` | занятые столики на дату и время |
| `POST` | `/api/bookings` | забронировать столик |

## Особенности реализации

- **Безопасность данных:** SQL-запросы только с параметрами (`?`) — защита от SQL-инъекций; пользовательские данные выводятся через `textContent` и экранируются в письмах — защита от XSS; цены и состав заказа проверяются на сервере.
- **Транзакции:** заказ и его позиции сохраняются атомарно. При бронировании используется `BEGIN IMMEDIATE`, чтобы два гостя не могли одновременно занять один столик.
- **Миграции:** при обновлении структуры таблиц база дополняется новыми столбцами без потери данных.
- **Статусы:** у заказов и броней есть поле `status` — основа для будущей панели персонала.
- **Секреты** хранятся в `.env` и не попадают в репозиторий.
